📖 How to connect to Airbnb & Booking.com in 60 Seconds:

  1. Airbnb: Go to Airbnb Host Dashboard ➔ Pricing & Availability ➔ Calendar Sync ➔ Import Calendar. Paste the respective room's URL from above.
  2. Booking.com: Go to Extranet ➔ Rates & Availability ➔ Sync Calendars ➔ Add Calendar Connection. Paste the URL.
  3. Done! Both platforms will now continuously pull live availability from Cool-Cat.
